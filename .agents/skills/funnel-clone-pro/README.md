# Funnel Clone Pro V7

Skill para agentes de desenvolvimento como Codex, voltada à reconstrução autorizada de funis próprios, quizzes, páginas de vendas e VSL com fidelidade visual e funcional.

## Instalação
Extraia a pasta `funnel-clone-pro-v7` no diretório de skills do seu ambiente Codex (por exemplo `.agents/skills/` do projeto). Verifique o caminho de instalação suportado pela sua versão do Codex. O arquivo principal é `SKILL.md`.

## Uso
Peça: “Use a skill Funnel Clone Pro para reconstruir este funil de minha propriedade: [URL]. Modo automático. Quero preview antes da publicação.”

## Incluído
- Dois modos: automático e por etapas
- Navegação por ramificações, checkout e ofertas de saída
- Comparação visual e relatórios
- HTML exportável, prévia e publicação mediante aprovação
- Meta Pixel, GA4, TikTok, A/B, SEO, backups, edição simplificada, CRM, segurança, VSL, monitoramento e gestor de ofertas

## Limites
Skill é um conjunto de instruções, não uma plataforma de hospedagem ou monitoramento. Recursos dependem de navegador, ferramentas, credenciais e serviços disponíveis. Não realiza pagamentos reais nem publica em produção sem aprovação. Não há garantia de fidelidade absoluta ou URL público sem infraestrutura.
